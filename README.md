
# ⚙️ iOS Settings Screen

Реализованный экран настроек в стиле iOS с кастомными ячейками, анимациями и соответствием гайдлайнам Apple Human Interface Guidelines.

## 🎥 Демонстрация

## 📱 Возможности

### 🎨 Интерфейс
- **Кастомные ячейки** - уникальный дизайн для каждого типа настроек
- **Группировка по секциям** - логическое разделение настроек
- **Автоматическая адаптация** - поддержка Light/Dark mode
- **Плавные анимации** - нативные переходы и взаимодействия

### 🔧 Функциональность
- **Различные типы ячеек**:
  - Профиль пользователя (аватар + имя)
  - Переключатели (UISwitch)
  - Настройки с дополнительной информацией
  - Настройки с индикатором доступа
- **Динамическая высота ячеек** - автоматическая подстройка под контент
- **Нативная навигация** - переходы между экранами

### 🛠 Технические особенности
- **100% Programmatic UI** - без использования Storyboard/XIB
- **Auto Layout** - адаптация под все размеры экранов
- **Модульная архитектура** - легко расширяемая кодовая база
